# Code of Conduct

NexRhythm aims to maintain a respectful, constructive, and technically useful open-source community.

This Code of Conduct applies to project spaces including issues, pull requests, reviews, discussions, and other project-managed communication channels.

## Expected Behavior

Participants are expected to:

- communicate respectfully and professionally;
- discuss ideas, code, and behavior rather than attacking individuals;
- provide technical feedback that is specific and actionable;
- accept reasonable disagreement without hostility;
- respect differences in experience, background, language, and perspective;
- keep discussions relevant to the project;
- help maintain a welcoming environment for new contributors.

## Unacceptable Behavior

The following behavior is not acceptable:

- harassment, intimidation, threats, or personal attacks;
- discriminatory or demeaning comments;
- sexualized language or unwanted sexual attention;
- deliberate disruption, trolling, or repeated off-topic behavior;
- publishing another person's private information without permission;
- abusive conduct directed at maintainers or contributors;
- spam or malicious submissions.

## Technical Disagreement

Strong technical disagreement is allowed.

Criticism should focus on:

- behavior;
- implementation;
- architecture;
- evidence;
- trade-offs.

Technical disagreement must not become personal conflict.

## Enforcement

Project maintainers may edit, remove, reject, lock, or close contributions and discussions that violate this Code of Conduct.

Depending on severity and repetition, maintainers may also restrict or block participation in project spaces.

Enforcement decisions should be based on behavior shown in the project, not personal disagreement with a participant.

## Reporting

If a Code of Conduct concern cannot safely be raised in a public issue or pull request, contact the maintainer through an available private contact method associated with the project or maintainer profile.

Do not publish sensitive personal information in public project channels.
